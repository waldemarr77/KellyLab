# KellyLab — Ідея проекту

## Для кого і навіщо
Платформа для IT-спеціалістів які готуються до технічних співбесід.
Допомагає систематизувати питання, зрозуміти відповіді і попрактикуватись.

---

## Основний флоу

1. **Реєстрація** — юзер вказує email, пароль, потім (другий крок) посаду і рівень (trainee / junior / middle / senior)
2. **Завантаження питань** — юзер завантажує файл з питаннями (PDF, DOCX або TXT) з будь-якого джерела
3. **AI обробка** — штучний інтелект читає кожне питання, максимально просто пояснює і генерує ідеальну відповідь для співбесіди
4. **Q&A картки** — відкривається вікно з усіма питаннями і відповідями від AI
5. **Редагування** — юзер може змінити будь-яке питання або відповідь під себе
6. **Скачування** — готовий матеріал можна скачати у зручному форматі (PDF, DOCX або TXT)

---

## Практика

- **Практика до питань** — AI автоматично генерує практичне завдання до кожного питання. Юзер пише код з нуля.
- **Незалежні задачі** — окремий розділ із задачами типу LeetCode: є умова, шаблон коду (skeleton), тест-кейси, рівень складності (easy / medium / hard). Юзер вирішує задачу, отримує фідбек.

## Технічний стек

### Мій бекенд
- Python, Django, Django REST Framework
- PostgreSQL + pgvector (семантичний пошук)
- Redis + Celery (фонова обробка AI)
- LangChain, LangGraph, HuggingFace
- AI: Gemini (gemini-1.5-flash) як основний, Llama як fallback

### Бекенд колеги (151metr)
- FastAPI
- **Parser service** (port 8001) — приймає файл, повертає список питань
- **Exporter service** (port 8002) — приймає питання + відповіді, генерує PDF/DOCX/TXT

### Фронтенд (планується)
- React + Vite

## Правила роботи з AI-асистентом
- **Пояснювати код** — перед написанням або змінами обов'язково пояснити що і навіщо. Я сам пишу код, асистент лише пояснює.
- **Не редагувати файли без дозволу** — жодних змін у файлах проекту без мого явного прохання.
